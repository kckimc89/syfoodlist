어린이 음식도감 V29 - 최종 기준 버전

목표:
- iPad 홈 화면 웹앱을 주 사용환경으로 고정
- Safari와 홈 화면 웹앱의 저장공간 분리를 전제로 설계
- 현재 실행 중인 origin에 음식/사진을 저장
- Storage API로 persistent storage 요청
- 사진을 IndexedDB에 저장
- 음식 + 카테고리 + 사진을 포함한 ZIP 백업
- ZIP/JSON 복원
- 저장공간 사용량/사진 수/음식 수 확인
- 이후 V30 이상은 같은 GitHub Pages 주소의 파일만 교체

중요:
Safari에서 만든 데이터를 홈 화면 앱으로 자동 복사할 수는 없습니다.
V29 설치 후에는 홈 화면 앱에서 새 데이터를 등록하세요.
기존 Safari 데이터는 Safari에서 별도로 백업하고, 홈 화면 앱에서 복원하는 방식으로 옮깁니다.
